# Exam module removed

The exam setup, scheduling, marks approval, publication, report cards, results portal, reminders and exam navigation have been removed. Teacher quizzes, quiz marks/import/export, grading and student progress remain available. Class quiz shortcuts now open the quiz list.

Database tables, historical migrations and compatibility models are retained to preserve saved exam records and foreign keys shared with quizzes. Archived exam assessments remain excluded from standalone quiz lists and edits. No database records were deleted. Student/parent login opens a basic school portal.

Earlier exam implementation documents describe the former module and are historical.
